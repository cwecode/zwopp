# Code of Conduct

Zwopp wants to be a friendly project for everyone, regardless of age, body, disability,
ethnicity, gender identity and expression, experience, nationality, appearance, religion
or sexual orientation.

## Expected

- Be kind and patient, especially with newcomers.
- Criticise ideas and code, not people.
- Accept feedback gracefully and admit mistakes.
- Assume good intent, and ask when something is unclear.

## Not accepted

- Insults, harassment, trolling, and sexualised language or images.
- Personal or political attacks.
- Publishing other people's private information without their permission.
- Anything else that would be inappropriate in a professional setting.

## Scope and enforcement

This applies in all project spaces: issues, pull requests, discussions and reviews. The
maintainer may edit or remove contributions that break it, and warn or block the people
who made them.

To report a problem, contact the maintainer privately via the
[maintainer's GitHub profile](https://github.com/cwecode), or use GitHub's *Report content*.
Reports are handled confidentially.

This code is based on the [Contributor Covenant](https://www.contributor-covenant.org),
version 2.1.
