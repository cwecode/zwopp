Show it, don't type it

The editor is made for explaining: everything you need to point at something is one key away, and one shortcut puts the finished image on the clipboard.

  • Work instructions and how-tos: numbered steps, arrows and mouse stamps for “click here, then there” – a guide in one picture.
  • Quick answers in chat: capture, mark the spot, Ctrl+Shift+C (⌘⇧C on a Mac), paste into Teams, Slack or an email. Done in under a minute.
  • Bug reports and feedback: a callout says what is wrong, a GIF shows how it happens, pixelate hides what nobody should see.
  • Share it your way: copy, drag the image into any app, or export PNG, JPG, WebP or an animated GIF. Annotations stay editable for the next version.

Why Zwopp?

An editor made for explaining

Arrows, step numbers, callouts, mouse stamps, magnifier, highlighter and pixelate. Annotations stay editable; the original is never changed.

Shared in seconds

Copy the finished image or drag it into Teams, Slack, an email or a ticket. GIFs stay animated.

A library, not a folder

Every capture is kept, sorted by date and by the application it came from, and found again by title or tag – fast even with 100 000.

Scrolling shots and GIFs

A panorama joins a long page while you scroll. A GIF records a click sequence, ready to paste into a chat.

Freeze first, select later

One hotkey freezes every monitor. Drag a region, click a window, or Shift+click a whole screen – with a magnifier at the cursor.

For scripts and AI agents

zwopp capture --window Firefox takes a screenshot from the command line; Claude Code gets a skill with one click.

Local, private, yours

No account, no cloud, no telemetry – Zwopp sends nothing anywhere. Export the whole library any time, with readable names and tags.

On every desktop

Windows 10 and 11, macOS on Apple silicon and Intel, Linux including Wayland. One codebase in Rust, open source.

Screenshots for your AI agent

AI agents take screenshots, find them in your library and look at them – “take a screenshot of the login dialog and attach it to the issue”. They run Zwopp's command line, on Windows, macOS and Linux.

  • Claude Code: Settings › AI agents and command line › Install skill. The skill costs context only when it is used.
  • Other agents with a terminal run the same commands.
  • Scripts use the same executable, with --json output.
# the window an agent should show
zwopp capture --window "Firefox" --title "Login error" \
  --tag bug --out ./login.png --json

# find earlier ones
zwopp list --search "login" --json

# hand it to the user to annotate
zwopp open <id>
